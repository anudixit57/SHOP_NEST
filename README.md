# 🛍️ ShopNest

ShopNest is a full-stack MERN e-commerce web application where users can browse products, add items to the cart, make secure payments using Razorpay, and track their orders. It features JWT authentication, a responsive UI, and a seamless shopping experience.

## 🚀 Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Redux Toolkit
- Razorpay
- Cloudinary

## ✨ Features
- User Authentication
- Product Listing & Search
- Shopping Cart
- Secure Razorpay Payments
- Order History
- Responsive Design
